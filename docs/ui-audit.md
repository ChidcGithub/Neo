## 一、产品形态与信息架构

**产品定位**：教室一体机上的 AI 助教（Windows，86~98 吋大屏，4~10 米观看距离）。
**双模态入口**：键鼠/触控（主窗）+ 语音唤醒「嗨，Neo」（全程后台）。

### 页面清单

| 页面/状态 | 文件 | 说明 |
|---|---|---|
| Hero（空态首页） | `ui/hero.rs` | 品牌标志 + 引导语 + 输入卡 + 4 张课堂场景卡 |
| 对话态 | `ui/conversation.rs` | 顶栏 + 消息流（Markdown/公式/工具行）+ 停靠输入卡 |
| 侧栏 | `ui/sidebar.rs` | 品牌区 / 新对话 / 会话列表（行内重命名+删除确认）/ 设置入口 |
| 设置面板 | `ui/settings.rs` | 全屏遮罩 + 居中卡片，六页签：通用/外观/显示/模型/记忆/关于 |
| 显示诊断面板 | `ui/settings.rs::display_tab` | 缩放链路诊断（密度 × 距离 → 最终倍率） |

## 二、布局逻辑

### 2.1 主窗骨架

```text
┌──────────┬─────────────────────────────────┐
│ 侧栏      │ 顶栏（会话标题/距离 chip/主题钮/新对话）│
│ 260pt     │ 内容列（居中，宽 min(920×s, 可用−64×s)）│
│          │ 输入卡（列宽 + 32×s，共用左基线）        │
└──────────┴─────────────────────────────────┘
```

- **内容列居中**而非贴侧栏 —— 与上游一致；列宽保留 920px 扫读上界，窄屏收缩；
- **输入卡比内容列宽 32×s**、共用左基线 —— 上游的「卡片略宽于内容」手势；
- Hero 与对话共用同一张输入卡（`ui/composer.rs`），位置不同（中央 vs 底部停靠）；
- 侧栏会话行动作钮（重命名/删除）**恒显** —— 教室触控没有 hover。

### 2.2 缩放链路（Neo 原创，上游没有）

```text
像素密度因子 = 视口逻辑高 / 1080
距离系数     = 近距 1.0 · 教室 1.25 · 远距 1.6
最终倍率     = clamp(密度 × 距离, 0.85, 2.8)
```

**所有**度量（字号/间距/圆角/图标）过 `Metrics::s(x)` 乘最终倍率 ——
让界面占据的**视角**（而非像素数）保持稳定。这是 Neo 最核心的布局资产。

### 2.3 触控命中

视觉尺寸沿用上游原值（28/34px 圆钮），命中区单独扩到 `max(视觉, 48pt×s)`。
1080p 近距下生效（28→48），4K 一体机下视觉本身已超 70px，扩边自动失效。

## 四、色彩体系

### 4.1 三层 token 架构

```text
静态色阶（deepseek::D50..D800 / neutral::N_00..N_1000 / 状态色）
   ↓ 语义别名
Palette（bg_base / label_* / accent / border_l1..l4 / hover …）  明暗各一套
   ↓ 组件封装
Components（btn_* / mask_* / error_soft / code_* / nav_* …）     明暗各一套
```

- 明暗判别：看 `bg_base` 亮度（`< 3×128` → 暗色组件 token），不写死枚举；
- **亮色是一等公民**（教室亮环境）：`Palette::LIGHT` 每值独立取自上游，非暗色推算；
- 预乘 alpha 工具函数 `rgba()/white_a()/black_a()` —— 暗色用白叠加、亮色用黑叠加。

### 4.2 关键色值

| 语义 | 暗色 | 亮色 |
|---|---|---|
| 背景 `bg_base` | `#151517` | `#FFFFFF` |
| 强调 `accent` | `#679EFE`（D400） | `#4176E6`（D500） |
| 强调弱底 `accent_soft` | `#34415B`（D800） | `#E4EDFD`（D100） |
| 墨色 `brand_ink` | `#F9FAFB` | `#0F1115` |
| 成功/警告/错误 | `GREEN_500 / AMBER_500 / RED_400` | 同 / 同 / `RED_600` |

> **缺口**：`accent` 就是 DeepSeek 品牌蓝 —— Neo 界面上最显眼的颜色是别人的品牌色。

## 五、字体与排版

| 族 | 链路 | 用途 |
|---|---|---|
| Proportional | Segoe UI → 微软雅黑 | 界面文字 |
| `neo-bold` | Segoe UI Semibold → 雅黑 Bold | wt500+（标题/chip/按钮） |
| `neo-mono` | Consolas → 雅黑 | 代码（**不接裸 monospace**，防中文掉宋体） |
| 链尾 | NotoEmoji / emoji-icon-font | emoji 不豆腐块 |

字号阶梯（基准 1×）：caption 12 / label 13 / body 14 / headline 26。
列表排版的「标记栏固定宽 + 数字右对齐」是自己实现的（`design-kit.md` 有专节）。

> **缺口**：字号阶梯是上游的 12/13/14 桌面配比；中文在远距大屏上的
> 辨识度逻辑（笔画密度 vs 字号）没有被显式建模。

## 六、交互逻辑

| 模式 | 说明 | 来源 |
|---|---|---|
| 动作回报 | 组件返回 `Response/Outcome`，页面改状态 | 上游模式 |
| 恒显动作钮 | 列表行的编辑/删除不藏 hover 后 | **Neo 原创**（触控） |
| 行内编辑 | 重命名/确认都在行内完成，不弹窗 | **Neo 原创** |
| 点别处取消 | 删除确认条：点行外或 Esc 取消（有专门测试钉住） | **Neo 原创** |
| 语音唤醒 | 唤醒 → 跑马灯 + 听写 → 首句转出即发送；点击任意处打断丢弃 | **Neo 原创** |
| 工具权限 | 风险分级（read/open/write/exec），确认窗独立弹出 | **Neo 原创** |
| 记忆 | remember/forget 工具 + 设置页管理 + 分记忆 | **Neo 原创** |
| 课堂总结 | 最大化沿触发 → 截屏+转写 → 静默 2min 打磨 → 顶部弹窗 | **Neo 原创** |

> 结论：**交互层 Neo 已经很有自己的东西**；视觉层几乎全是别人的。

## 九、差异化缺口分析（结论）

| 层 | 自有度 | 缺口 |
|---|---|---|
| 交互/功能 | ★★★★☆ | 语音链路、权限流、课堂总结都是独有场景 |
| 布局/缩放 | ★★★★★ | 密度×距离链路业界少见 |
| 动效 | ★★★☆☆ | 边缘流光是独有签名，但未规范化、未品牌化 |
| 形态 | ★★★☆☆ | squircle 是上游规范；但工程实现与一致执行是自有资产 |
| **色彩** | ★☆☆☆☆ | **最显眼的颜色是 DeepSeek 蓝** |
| **图标** | ★☆☆☆☆ | **全部来自上游包**（除 Mic） |
| **标志** | ★☆☆☆☆ | **鲸鱼路径原样取自上游** |
| 排版 | ★★☆☆☆ | 桌面配比直接沿用，中文远距阅读未建模 |

**重塑优先级**（辨识度收益 ÷ 工程成本）：

1. **色彩** —— 换 accent 系是单点改动、全局生效，收益最大；
2. **动效签名成文** —— 边缘流光已是代码现实，只需规范 + 复用到更多触点；
3. **图标风格规则** —— 以 Mic 为基准立规，新图标按新规画，存量逐步替换；
4. **排版** —— 补中文远距字阶，不动骨架；
5. **标志** —— 鲸鱼形象深入人心（且已在课程记忆里），**保留轮廓、重绘几何**
   比换标志更明智：做「Neo 鲸」的再设计（更几何、更正面、可描边化）。

→ 品牌视觉语言见 **`neo-brand.md`**；落地规范见 **`ui-design-spec.md`**。
