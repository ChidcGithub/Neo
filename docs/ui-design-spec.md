# Neo UI 设计规范（品牌版）

> 三部曲的落地篇：`ui-audit.md` 盘点现状 → `neo-brand.md` 定义基因 →
> **本文把基因落到页面、组件、动效与适配上**，并逐项做工程可行性验证。
>
> 与既有文档的关系：`design-spec.md` 记录 token 的**上游来源**（历史账本），
> `design-kit.md` 是组件**接口手册**；本文是**设计规范** —— 冲突时以本文为准。
>
> 文中的「高保真设计稿」= `docs/screens/*.png` —— 由离屏渲染管线
> （`cargo test -p neo-app`）用与真机完全相同的字体/主题路径渲出的像素图，
> 比原型工具的画稿更「高保真」；改设计就跑测试刷新它们。

### 1.2 语义映射（改动点全表）

| `Palette` 字段 | 亮色 旧 → 新 | 暗色 旧 → 新 |
|---|---|---|
| `accent` | `#4176E6` → **T600** | `#679EFE` → **T400** |

`design-spec.md` 第二章全表。

### 1.3 使用纪律（沿用并加严）

- 页面**禁止**裸写 `Color32`：组件色走 `d.c()`，表面色走 `d.p()`；
- accent 只允许出现在：主操作、链接、选中态、状态点、**边缘流光**；
- accent 底上的文字一律反色（`on_info`），不把 accent 当小字色用。

## 二、页面设计（高保真稿 + 品牌落点）

### 2.1 Hero（空态首页） — 稿：`01-hero-dark-1080p.png` / `02-hero-light-1080p.png`

```text
                [鲸标] 今天想在课堂上做点什么？
                ─────────────────────────────
                [选择工作区            v]
                ┌──────────────────────────────┐
                │ 问点什么，或挑一个课堂场景        │
                │ +  [Plan][只读]   [模型 v] [↑] │
                └──────────────────────────────┘
                [课堂讲解] [随堂测验] [作业批改] [课堂记录]
```

- 品牌落点：鲸标居中微浮（游动相位 1.6s）；发送钮 Accent 圆 = 鲸青；
  场景卡选中态描边 = accent；「Plan / 只读」chip 选中底 = accent_soft。
- 交互：场景卡点击填充输入框；`+` 附件；发送钮禁用 = 淡出 40%（**不是**消失）。

### 2.2 对话态 — 稿：`04/05-conversation-*.png` / `08-generating-1080p.png`

- 顶栏：标题居中；右侧距离 chip + 主题钮 + 新对话（顺序摆放，禁各自锚点）；
- 消息流：内容列居中（§三-2）；AI 消息无气泡（全宽正文），用户消息气泡 = T50（亮）；
- 生成中：pending 三点（v2 候选改鲸息气泡）+ 停止钮；
- Markdown：代码块层 `bg_layer_2`、行内代码 `code_inline`、
  引用条 `accent` 左侧 3pt 竖条；公式走 `ui/math.rs`（`16-math-1080p.png`）。

### 2.3 设置面板 — 稿：`11-settings-appearance-1080p.png` / `18-settings-model-1080p.png`

- 全屏遮罩（`mask_modal`）+ 居中卡（720×540×s，固定尺寸内容滚动）；
- 左列导航：当前项 `nav_active` 底 + 图标 accent；右列页标题 + 描述 + 内容；
- 行态：开关行 52×s、键值行、hint 灰字行；动作全部恒显。

### 2.4 弹窗族（独立视口）

| 窗 | 位置 | 动效 | 稿 |
|---|---|---|---|
| 迷你窗 | 屏幕角落（避让鼠标） | 边缘流光（执行中）+ 淡入 0.25s | （真机） |
| 确认窗 | 屏幕中央偏上（0.42h） | 直接出现（要用户立刻看见） | `15-tool-confirm-1080p.png` |
| 课堂总结窗 | 顶部居中 y=20×s | 滑入 0.35s ease-out | （真机） |
| 截屏闪光 | 被截区域 | 白框 0.9s（13% 快入+缓出） | （真机） |
| 跑马灯 | 全屏边缘 | 折射光环 + 电平起伏 | （真机） |

弹窗共性纪律：透明视口、恒可见休眠 1x1 挪屏外（杜绝闪黑）、不抢焦点。

## 三、组件交互规范

### 3.1 状态矩阵（所有可交互组件必须实现的状态）

| 状态 | 视觉 | 触发 |
|---|---|---|
| Idle | token 静息色 | — |
| Hover | 叠 `hover`（亮 6% / 暗 8%）或 `_hover` 变体色 | 指针进入（**触控无此态，设计不得依赖**） |
| Pressed/Active | 叠 `active`（10~14%） | 按下 |
| Disabled | 淡出 40%（Accent）或 `dimmed` 色 | 不可用 |
| Loading | Spinner 替换图标，尺寸不变 | 异步进行中 |
| Selected | accent 描边 + accent_soft 底 | 选中 |

### 3.2 全局交互约定（沿用，逐条仍是强制项）

1. **动作只回报不执行**（组件返回 Response/Outcome）；
2. **命中区 ≥ 48×s pt**（视觉不变）；
3. **Id 同容器唯一**（不能只靠文字区分；两组相同选项的 Segmented 必须 `id_salt`）；
4. **危险操作就地确认**（删除确认条：点行外/Esc 取消）；
5. **文本输入 salt 恒定**（防焦点丢失）；
6. **后台状态可见**：AI 在忙而主窗隐藏时，迷你窗必须让进度可瞥见。

### 3.3 语音链路交互（Neo 独有场景）

```text
待机 →(唤醒词, 连续2帧过线)→ 聆听（跑马灯亮 + 电平起伏）
聆听 →(点击任意处)→ 取消（丢弃识别，toast 提示）
聆听 →(首句转出)→ 新会话发送（不续上次上下文）
聆听 →(15s 沉默)→ 自动收场
```

## 四、动效规则

### 4.1 时长与曲线

| 档 | 值 | 用途 |
|---|---|---|
| fast | 0.1s | hover/开关 |
| **base** | **0.2s** | 面板开合、淡入淡出（默认档） |
| slow | 0.3s | 模态/舞台切换 |
| 滑入 | 0.35s | 顶部弹窗 |
| 曲线 | `ease-out-cubic`（Neo）/ `cubic-bezier(.4,0,.2,1)`（悬停） | 全站统一 |

### 4.2 品牌签名：边缘流光（Edge Beam）

| 参数 | 值 |
|---|---|
| 语义 | 只在「AI 聆听/执行/打磨中」出现 |
| 形态 | 沿 squircle/屏幕边缘的 beam，拖尾 30% 弧长，k² 渐隐 |
| 速度 | 2.4s/圈（卡片）；跑马灯呼吸 0.5x |
| 颜色 | **accent（鲸青）**（迷你窗 beam 已是 accent 驱动，换色自动跟随） |
| 密度 | 同屏 ≤ 2 处；聆听与执行错峰 |
| 技术 | 弧长参数化采样，28 片/圈；回调自驱 60fps（子视口） |

### 4.3 反规则（评审一票否决项）

- ❌ 弹跳/弹性曲线（课堂不需要俏皮）；
- ❌ 内容区内的循环动效（流光只走边缘）；
- ❌ 依赖 hover 才可见的信息或操作；
- ❌ 快于 0.1s 或慢于 0.5s 的过渡（要么瞬态要么庄重）。

## 五、多端适配方案

### 5.1 缩放链路（唯一入口 `Metrics::s`）

| 场景 | 逻辑高 | 距离档 | 倍率 | 正文 |
|---|---|---|---|---|
| 1080p 桌面近距 | 1080 | 近距 | 1.00 | 14pt |
| 1080p 一体机 | 1080 | 教室 | 1.25 | 17.5pt |
| 4K 一体机 | 2160 | 教室 | 2.50 | 35pt |
| 4K 报告厅 | 2160 | 远距 | 2.80（截顶） | 39.2pt |

- 上界 2.8 防 4K 远距把输入卡撑爆；下界 0.85 防小窗密度倒挂；
- 列宽：`min(920×s, 可用 − 64×s)`；输入卡 = 列宽 + 32×s。

### 5.2 主题与环境

- 亮色 = 一等公民（教室亮环境）；暗色 = 暗教室/晚间备课；
- 主题切换一键（顶栏），不写系统跟随（一体机环境固定）。

### 5.3 输入模态

- 鼠标 / 触控（命中区扩展）/ 键盘（Enter 发送、Esc 关面板）/ 语音（唤醒词）；
- 弹窗不抢焦点（`with_active(false)`），按钮靠点击；
- **后台可用性**：主窗托盘后，聆听/执行/确认/总结全部可达 —— 这是 Neo
  与桌面聊天应用的本质差异，任何新功能设计必须回答「主窗藏着时它怎么办」。

## 六、落地性验证（对照 egui/工程约束逐项核对）

### 6.1 换色实施路径（鲸青落地）

| 步骤 | 位置 | 风险 |
|---|---|---|
| 新增 `whale` 色阶模块 | `neo-theme/src/palette.rs` | 无（纯常量） |
| accent/accent_soft/bubble/link 换值 | `Palette::{LIGHT,DARK}` | 无（单点） |
| `Components::{btn_info,business,*_soft}` 换值 | 同文件 | 无（单点） |
| 迷你窗 beam | **无需改**：已是 `tint(p.accent)`（`miniwin.rs:363`，已核对），换色自动生效 | — |
| 跑马灯颜色 | **无需改**：shader 折射桌面像素，无品牌色硬编码（已核对 `shader.wgsl`） | — |
| 刷新快照 | `cargo test -p neo-app` 重渲 `docs/screens/` | 人工核对一遍 |

> token 架构红利：全站 accent 收敛于 2 个常量点（Palette + Components），
> 组件层零改动。这正是「页面不写裸 Color32」纪律的回报。

### 6.2 技术约束核对表

| 设计项 | egui 约束 | 结论 |
|---|---|---|
| squircle(1.5) | 无原生支持；`neo_theme::squircle` 自研多边形光栅 | ✅ 已落地 |
| 双轮廓挖空图标 | epaint 三角扇不支持；自研扫描线（nonzero/even-odd） | ✅ 已落地，有测试钉住 |
| 边缘流光 | 弧长参数化 + 28 片 quad；子视口回调自驱 60fps | ✅ 已在迷你窗运行 |
| 滑入弹窗 | deferred 视口 + OuterPosition 命令；避开 builder patch | ✅ 已在课堂总结窗运行 |
| 透明视口 | 恒可见 + 屏外休眠（切 Visible 首帧闪黑） | ✅ 已成文纪律 |
| 文本竖排/标点悬挂 | 不支持 | 规范未采用 ✅ |
| 粒子/复杂 shader（主窗内） | egui 仅 2D 图元；复杂效果走 neo-overlay（wgpu/DX12） | 规范限定流光在边缘图元范围内 ✅ |
| 动画帧率 | 主窗托盘后 10fps 节流；动画必须放子视口回调自驱 | 已在动效规则注明 ✅ |
| 远距字阶 | `Metrics::s` 全局乘子，无断点式重排 | 规范只缩放不重排 ✅ |

### 6.3 性能预算

| 项 | 预算 | 现状 |
|---|---|---|
| 空闲帧 | ≤ 10fps（后台 2fps） | 达标 |
| 流光卡片 | 60fps × 28 quad ≈ 零感 GPU | 达标 |
| 跑马灯 | 0.6x 离屏渲染（省 ~65% GPU） | 达标 |
| 图标 | 光栅化一次入纹理，绘制 = 贴图 | 达标 |

## 七、内部评审 checklist（设计独特性 × 体验合理性）

### 独特性

- [ ] 遮住 logo，能凭**青 / 微鼓 / 边缘流光**认出 Neo 吗？
- [ ] accent 与 DeepSeek 蓝并排放，3 米外能分清吗？（色相 222° vs 192°）
- [ ] 新增一枚按 §四规则画的原创图标（建议 Sparkle），与存量混排不违和吗？

### 体验合理性

- [ ] 亮色 accent（T600）白底对比度 4.9:1 —— 后排学生可读；
- [ ] 同屏流光 ≤ 2 处 —— 课堂上不吵；
- [ ] 所有操作不依赖 hover —— 触控可行；
- [ ] 主窗隐藏时：唤醒、授权、总结三条路径全部可达 —— 后台场景闭环；
- [ ] 打断路径对称：语音可打断（点击）、生成可打断（停止钮/确认）；
- [ ] 换色后快照全量人工过一遍（重点：场景卡选中态、chip、发送钮、链接）。

### 通过标准

上述全部 ✅ + `cargo test -p neo-app` 快照刷新后无意外像素差
（预期差异 = 蓝色像素变青色像素，其余不动）。
