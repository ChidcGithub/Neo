# Neo

## 使用

支持 Windows 10 2004（19041）及以上的 x64 系统。解压后运行 `neo.exe`，不要单独移动主程序或删除配套资源。首次使用在「设置 → 模型」配置服务与密钥。

课堂安全模式默认开启：暂停后台采集并限制工具权限，但不是离线模式，问答和用户文件仍可能发送给配置的模型服务。

在「设置 → 通用 → 语言」切换中文 / English，选择自动保存。用户内容和模型回复不随界面语言翻译。

## 目录

- `resources/lang/`：中英文 `.lang` 语言文件。
- `resources/models/wake/`：唤醒模型。
- `resources/models/stt/`：语音转写模型。
- `runtime/onnx/`：ONNX Runtime。
- `runtime/gitbash/`：Bash 工具运行时。
- `docs/`：使用说明。
- 根目录 DLL：程序启动依赖，请保留。

## 数据与升级

数据默认位于 `%APPDATA%\Neo`，便携版也使用此位置；可通过 `NEO_HOME` 指定其他目录。

升级前退出 Neo，备份用户数据和自定义资源。安装器保留旧安装目录备份，不自动合并自定义文件；备份位置见安装详情。

卸载不会删除用户数据；非空资源目录和自定义文件也会保留，请确认并备份后再手动清理。

## 启动故障

先确认文件完整和显卡驱动可用。更新驱动后，可运行 `neo.exe --reset-renderer` 重新检测渲染器。安装包未签名时，Windows 可能提示 SmartScreen 警告，请确认下载来源。
