# Neo 品牌视觉语言（鲸 · 光 · 课堂）

> 承接 `ui-audit.md` 的缺口分析：现有界面的**交互与缩放是 Neo 自己的，
> 色彩、图标、标志是上游 DeepSeek Harness 的**。本文定义 Neo 的专属视觉基因 ——
> 不是换一层皮，而是把产品上**已经存在但没说出来的东西**提炼成规则，
> 再把「最显眼位置上的他人资产」替换成自有资产。
>
> 落地细节（页面稿、组件交互、动效参数、适配、可行性验证）在 `ui-design-spec.md`；
> 本文只回答两个问题：**Neo 长什么样？为什么长这样？**

---

## 一、品牌核心事实（不可协商的出发点）

| 事实 | 设计含义 |
|---|---|
| 名字是 **Neo**，唤醒词是「嗨，Neo」 | 品牌是「被叫出来」的 —— **听见**是第一动作 |
| 标志是**鲸鱼** | 深海、沉静、巨而温柔；鲸鱼靠**声音**感知世界 —— 与语音唤醒天然同构 |
| 跑在**教室大屏**上 | 亮环境为主、观看距离 4~10 米、扫读而非细读 |
| 用户是**老师与学生** | 不炫技、不分散课堂注意力；安静、可信、一叫就应 |
| 已有动效资产：全屏跑马灯 / 卡片边缘流光 | 「**光沿边缘流动**」已是事实签名，扶正为品牌动效 |

一句话品牌概念：**深海里的声与光** —— 鲸在黑暗深海靠声波定位（聆听），
Neo 在课堂后台靠唤醒词待命（聆听）；它出现时带着边缘的流光（应答）。

---

## 二、基因 ①：鲸青（Whale Teal）—— 专属色彩

### 为什么换掉 DeepSeek 蓝

上游 accent `#4176E6 / #679EFE` 是**紫向蓝**（色相 ≈ 222°），
它是 DeepSeek 的品牌识别。Neo 的鲸走向**青向蓝**（色相 ≈ 192°）：
深海海水的颜色，与紫蓝相差 30° 色相 —— 并排肉眼立辨，又不跳出
「可信的教育科技蓝」的大范畴。

### 鲸青色阶

```text
深渊 ▏T900 #072A36 ▏T800 #0D3D4E ▏T700 #0A5E77
中层 ▏T600 #0E7A99 ▏T500 #17A8C6 ▏T400 #4FC3DC
海面 ▏T300 #6FCCDF ▏T200 #A0E0EC ▏T100 #CDEFF5 ▏T50 #E9F8FB
```

| 角色 | 亮色主题 | 暗色主题 | 备注 |
|---|---|---|---|
| `accent`（主强调） | **T600 `#0E7A99`** | **T400 `#4FC3DC`** | 发送钮、链接、选中、流光 |
| `accent_hover` | T500 `#17A8C6` | T300 `#6FCCDF` | hover 向亮走（沿用上游方向） |
| `accent_soft`（弱底） | T100 `#CDEFF5` | T800 `#0D3D4E` | chip 底、选中底、徽章 |
| 气泡底 `bubble` | T50 `#E9F8FB` | 维持中性层 | 亮色气泡从蓝雾改青雾 |

**对比度承诺**（教室大屏的可读性底线，WCAG AA 思路）：

- T600 在白底上对比度 ≈ **4.9 : 1**（≥ 4.5，文字级达标）；
- T400 在 `#151517` 上对比度 ≈ **9.0 : 1**（远超 4.5）；
- 凡 accent 色上排文字，一律用「accent 底 + 反色字」而非「accent 字」。

**不动的部分**：语义色（成功绿 / 警告琥珀 / 错误红）全保留 ——
语义色的差异化只会伤害可识别性；中性偏蓝灰阶梯保留（与鲸青同族冷灰）。

## 三、基因 ②：微鼓形态 —— squircle(1.5) 的自觉化

上游规范、Neo 工程实现的 `superellipse(1.5)` 已经是全站统一的形态语言
（介于圆与方之间的「微鼓」）。从「碰巧沿用」升级为「**主动承诺**」：

1. **一切矩形曲面只用 K=1.5**：卡片、按钮、chip、输入框、弹窗、场景卡；
2. **纯圆只给严格圆形控件**（发送钮、开关钮、状态点）；
3. **圆角半径的语义**：卡片 22×s、chip 8×s、面板 16×s —— 数字可沿上游，
   但「任何新表面必须三选一」是 Neo 的自约束，杜绝随手新半径。

形态记忆点：**鲸腹的微鼓曲线** —— 不尖锐、不臃肿，与「巨而温柔」同构。

## 四、基因 ③：边缘流光（Edge Beam）—— 品牌动效签名

**这是 Neo 独有、上游没有的资产**（已有代码现实：跑马灯 edgeglow、
迷你窗 border beam）。规范化为统一语言：

| 参数 | 值 | 说明 |
|---|---|---|
| 语义 | **「Neo 在听 / 在想 / 在做」** | 只表达 AI 的活动状态，不做装饰 |
| 载体 | 边缘（窗口边缘 / 卡片 squircle 边缘） | 光沿边缘走，不占内容面 |
| 速度 | 2.4s / 圈（卡片）；呼吸 0.5x（跑马灯待机） | 慢到不抢课 |
| 拖尾 | 弧长 30%，k² 平方渐隐 | 已有实现参数扶正 |
| 颜色 | accent（鲸青） | 换色后全局自动生效 |
| 密度 | **同屏至多两处** | 聆听（全屏）与执行（卡片）互斥或错峰 |

**反规则**：不打字机光标、不弹跳、不闪烁提醒 —— 课堂上动效的任务是
「让人知道它在工作」，不是「让人看它」。

**候选演进（v2 标记）**：pending 三点呼吸 → 「鲸息气泡」（三点错相上浮
+ 淡出，1s/轮）—— 贴品牌且已有正弦相位基础设施，改动小、辨识收益中。

## 五、基因 ④：原创图标规则（双轮廓 · 圆头 · 16 栅格）

现状 22 枚图标逐字节来自上游（16/14 栅格**填充路径**），Mic 是唯一原创。
不重起炉灶（描边派系会废掉现有光栅化管线），而是**在同一技术体系里立自有规则**：

| 规则 | 值 | 理由 |
|---|---|---|
| 栅格 | 16（小场景 14） | 与现有管线一致 |
| 技法 | **填充路径 + 双轮廓挖空**，禁手绘描边 | 粗细/端点一致性由几何保证 |
| 线感 | 等效 1.6~1.8（16 栅格） | 远距可辨的下限 |
| 端点/转角 | **一律圆头**（半径 = 线宽/2） | 与 squircle 微鼓同族；上游是平头 |
| 角度 | 只用 45° / 90° | 杜绝「随手斜」 |
| 内留白 | ≥ 1pt | 小尺寸不糊 |

**以 `Mic` 为风格基准件**（已是原创），新图标一律按此规则绘制；
存量图标按使用频率逐步重绘：Sparkle（AI 语义高频）→ Board / Checklist
（课堂场景）→ 其余随改随到。每枚新图标进 `icons/paths.rs` 前先过
`rasterized_ink_matches_path_bounds` 这条既有测试。

## 六、基因 ⑤：中文优先的远距排版

现有字号阶梯（12/13/14/26）是桌面配比，Neo 的排版承诺：

1. **中文优先**：字体链、行高、截断都以中文方块字建模（西文随之）；
2. **正文行高 1.7**（24/14 现状扶正成文）：远距扫读的行距下限；
3. **计数与序号永远走标记栏**（固定宽 + 右对齐，已在列表实现），
   不进正文流 —— 杜绝比例字体下「`1.` 与 `10.` 不对齐」；
4. **标题短句化**：标题 ≤ 12 字（「今天想在课堂上做点什么？」就是范本），
   靠留白而非字号堆层次；
5. **大屏只放大，不改排**：所有排版参数过 `s(x)` 缩放链路，
   不在页面里写死任何 pt。

## 七、品牌化组件（新资产清单）

| 组件 | 说明 | 状态 |
|---|---|---|
| **EdgeBeamCard** 边缘流光卡 | squircle 卡 + accent 边缘 beam；AI 工作中态的标准容器 | 迷你窗已有实现，提为规范组件（收 neo-ui） |
| **SonarDot** 聆听点 | 唤醒聆听期的单点扩散涟漪（替代装饰性 loading） | v2 候选 |
| **场景卡**（已有） | 图标换原创规则件；选中态改鲸青 | 随图标替换落地 |
| **Neo 鲸标志** | 保留 silhouette、重绘几何：单色可 tint、可描边化、24 栅格化 | 品牌任务，另行评审（见下） |

### 关于鲸鱼标志的再设计（谨慎声明）

鲸鱼已深入产品（hero、加载、课堂记忆都在用），**不做形象替换**。
再设计方向：轮廓保留「身体 + 鳍 + 双眼」识别点；几何重建为 24 栅格上的
单轮廓 + 挖空（与图标同技法），得到一枚可任意 tint、可与图标排排坐的
**单色标**。产出前先出三稿对比，评审通过才替换 `brand/whale_path.rs`。

## 八、基因总表（一页速览）

| 基因 | 一句话 | 落点 |
|---|---|---|
| **鲸青** | 深海海水的青蓝，与 DeepSeek 紫蓝差 30° 色相 | `palette.rs` accent 系 |
| **微鼓** | 一切曲面 squircle(1.5)，纯圆只给圆控件 | 全站（已是现实） |
| **边缘流光** | AI 活动时光沿边缘走，同屏至多两处 | 跑马灯 / 流光卡 |
| **双轮廓圆头图标** | 16 栅格填充路径，端点一律圆头 | `icons/paths.rs` 渐进替换 |
| **中文远距排版** | 行高 1.7、序号走标记栏、标题短句化 | 已成文的排版承诺 |
| **鲸** | 聆听的巨兽：静、准、一叫就应 | 标志再设计（另评） |

> 验收问句（评审用）：把界面遮上 logo 放在一排同类 AI 产品里，
> 能不能凭**青、鼓、边缘流光**三样认出 Neo？—— 这就是差异化的及格线。
